# Nova Scientific Calculator

A responsive scientific calculator built with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome, Safari, Firefox, or Edge).
3. No installation or build process is required.

## Features
- Arithmetic, brackets, powers, factorials, percentages, reciprocal and constants (π and e)
- Trigonometry and inverse trigonometry
- Logarithms, natural logarithm and square root
- Degree/radian angle mode
- Live expression preview and previous answer (Ans)
- Calculation history drawer
- Memory keys (MC, MR, M+, M−)
- Dark/light theme
- Keyboard input

## Files
- `index.html` — app structure
- `style.css` — styling and responsive layout
- `script.js` — calculator logic
